How it works

Central rules. Local activation.

Profiles are shared assets, not owned by projects. A project manager can attach or remove them without changing other projects.

Block stops an invalid transcript submission. Warn surfaces issues but permits submission. Changes to a shared profile take effect for all assigned projects.
