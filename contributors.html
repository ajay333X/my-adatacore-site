Application flow

Clear expectations before project work begins.

Passing an application does not guarantee continuous work. Project access depends on current demand, language, quality needs and project eligibility.

01

03

Project guidelines, task limits, review decisions and feedback apply to production work.

Assessment expectations

Quality starts before the first task.

The assessment checks whether your setup and performance are suitable for the type of work you selected.

Voice Acting

  • Use a clear microphone and quiet recording environment.
  • Read the supplied script naturally rather than sounding like an announcement.
  • Listen to your recording before submitting.
  • Retry when needed before final submission.

Transcription

  • Listen carefully to the provided assessment audio.
  • Type only what is supported by the recording and project instructions.
  • Review spelling, punctuation and segmentation before submitting.
  • Reference text is not exposed to applicants during the assessment.
Before you apply

Know what the platform does and does not promise.

Professional contributor programs should be clear about eligibility, review and work availability.

What you can expect

  • A visible application status.
  • Project-specific guidance and review rules.
  • Quality feedback and change requests where the workflow supports them.
  • Authenticated support for account or project issues.

What is not guaranteed

  • Approval of every application.
  • Immediate project access after signup.
  • A minimum volume of tasks or continuous availability.
  • The same rate, task type or requirements across different projects.
