Release boundaries

This first version is an administrator-only collection tool. It does not publish customer-facing assets, alter contributor queues, or change the existing transcription pipeline. It supports approved Wikimedia Commons and Internet Archive downloads, authorized file uploads, local clip extraction, AI draft transcription using the configured provider, and metadata exports.
